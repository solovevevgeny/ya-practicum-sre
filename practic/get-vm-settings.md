# Получение доступа к кластеру Kubernetes для практики

Для выполнения практических работ в этом спринте вам понадобится Kubernetes. Мы предоставим вам доступ к виртуальной машине, на которой настроен однонодовый кластер. Ваша ВМ будет иметь характеристики:

* операционная система Ubuntu;
* 4 ядра и 8 GB операционной памяти;
* 60 GB HDD;
* предустановлены: helm, jq, curl.

**Важно**

Время работы виртуальной машины с кластером Kubernetes ограничено 10 часами. Затем ВМ отключится. Чтобы запустить её заново, нажмите на кнопку с ракетой.

Через 40 дней после создания ВМ удалится. Вы сможете пересоздать ВМ два раза.

В этом уроке вы подготовитесь к выполнению практических работ: получите доступ к ВМ с настроенным кластером Kubernetes и подключитесь к ней.

## Как получить доступ к ВМ

1. Перейдите к заданию и нажмите на кнопку с ракетой.

В течение 5-10 минут вам будут выданы:

* IP-адрес ВМ;
* Username для подключения (`ubuntu`);
* SSH-ключ для подключения.
* Сохраните полученный SSH-ключ:
  a. В корневой папке вашего компьютера создайте директорию `.ssh`, либо перейдите в неё, если она уже создана. Обычно она расположена по адресу `C:/Users/YourUsername/.ssh/` для Windows (`YourUsername` замените на нужное имя пользователя) и `~/.ssh` для MacOS.
  b. Внутри директории создайте файл `user_key` (с расширением txt  для Windows или без расширения для MacOS) и вставьте в него ключ.
  Файл с ключом должен выглядеть так, в конце должна быть пустая строка:
  []()![Содержимое файла приватного ключа OpenSSH: заголовок -----BEGIN OPENSSH PRIVATE KEY-----, за которым следует несколько строк Base64-кода, и в конце закрывающий заголовок -----END OPENSSH PRIVATE KEY-----. После последней строки ключа — пустая строка.](https://pictures.s3.yandex.net/resources/image_1755085186.png)

**Важно**

Не показывайте ваш приватный ключ никому ни при каких обстоятельствах.

3. Проверьте подключение к ВМ по SSH. Запустите команду в терминале:

```
ssh -i путь/к/ключу ubuntu@ip-адрес 
```

В течение 5-10 минут после создания ВМ на ней будет инициализироваться однонодовый кластер Kubernetes. Когда процесс настройки завершится, вы сможете посмотреть конфиг по пути `~/.kube/config`.

Вы можете выполнять практическую работу на полученной ВМ или скопировать конфиг для подключения к кластеру на локальную машину командой `scp ubuntu@<IP_ВМ>:~/.kube/config ~/.kube/config`.

Чтобы подключаться к кластеру из внешней сети, на локальной машине внесите изменения в полученный конфиг:

1. Откройте файл `~/.kube/config` на локальной машине.
2. В поле `server` укажите внешний IP-адрес виртуальной машины с кластером: `server: https://ВНЕШНИЙ_IP:6443`.
3. Удалите поле `certificate-authority-data`.
4. Добавьте поле `insecure-skip-tls-verify: true`.

Конфиг должен принять вид:

```
apiVersion: v1
clusters:
- cluster:
    server: https://<ВНЕШНИЙ_IP>:6443
    insecure-skip-tls-verify: true
  name: kubernetes
contexts:
- context:
    cluster: kubernetes
    user: kubernetes-admin
  name: kubernetes-admin@kubernetes
current-context: kubernetes-admin@kubernetes
kind: Config
users:
- name: kubernetes-admin
  user:
    client-certificate-data: ... # оставить как есть
    client-key-data: ...         # оставить как есть
 
```
